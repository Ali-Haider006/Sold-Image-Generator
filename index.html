This page needs to be served, not opened as a file.

Your browser blocks JavaScript modules on file://, so the controls are inert. From the project folder, run one of these and open the address it prints:

python3 -m http.server 8000
npx http-server -p 8000

Then visit http://localhost:8000. VS Code's Live Server extension works too.

Reversed logo — for designs that sit the mark on a dark ground

Some designs place the logo straight onto the brand colour with no white badge behind it. Add your white / reversed mark here and those designs will use it. Without one they fall back to flattening the main logo to a single colour, which keeps the silhouette but loses any inner detail.

Reversed logo Optional — white version, PNG with transparency
Water texture — used by designs that submerge the boat

A water cut-out ships with this tool and is used by default. Replace it with your own if you prefer; a stock image with a white sky works, since the white is keyed away automatically so the wave edge stays photographic.

Water texture Optional — the bundled one is used otherwise
Brush artwork — used by designs with a painted stroke

A dry-brush stroke ships with this tool. It is used as a stencil: its texture comes from the file, its colour from your logo, so the stroke is never stuck at whatever navy the artwork was drawn in. Dark-on-white artwork works; transparency is not required.

Brush artwork Optional — the bundled stroke is used otherwise
